# MAX — Платформы и приложения

## Какие платформы поддерживаются?
MAX доступен на: Android 7.0+, iOS 14.0+, Windows 10/11, macOS 11+, Linux (Ubuntu 20.04+,
Fedora 35+ в виде .deb/.rpm/AppImage). Веб-версия на max.example/web работает в Chrome 100+,
Firefox 100+, Safari 15.4+, Edge 100+.

## Где скачать десктоп-версию MAX?
Только с официального сайта max.example/download или из официальных магазинов: Microsoft
Store (Windows), Mac App Store (macOS), Flathub (Linux). Сторонние сайты могут предлагать
модифицированные сборки с вредоносным кодом — не скачивайте.

## Веб-версия vs десктоп — в чём разница?
Веб-версия (max.example/web) работает в браузере, не требует установки, но: нет звонков
(кроме Beta-режима в Chrome), медленнее работает с большими группами, нет интеграции с ОС
(контекстное меню, ярлыки). Десктоп-версия полноценна, поддерживает звонки, уведомления ОС,
горячие клавиши.

## Как обновить MAX?
Android — через Google Play или APK с сайта. iOS — через App Store. Desktop — автоматически
при запуске (или вручную через «Файл → Проверить обновления»). Web — обновляется на сервере,
перезагружать страницу после уведомления. Рекомендуется всегда последняя версия: исправления
безопасности и новые функции.

## Системные требования MAX для Windows?
Windows 10 версии 1903+ или Windows 11. RAM: 2 ГБ минимум, 4 ГБ рекомендуется для групп с
большим количеством медиа. Свободное место: 200 МБ для установки + кэш до нескольких ГБ.
.NET Framework 4.7.2+ устанавливается автоматически. ARM64 поддерживается в нативной сборке
с версии MAX 4.0.

## Поддерживается ли Linux официально?
Да: .deb для Ubuntu/Debian, .rpm для Fedora/RHEL, AppImage для остальных, Flatpak через
Flathub. Звонки работают только в .deb/.rpm (нужны кодеки), в AppImage — только текстовые
сообщения. ARM Linux (Raspberry Pi) поддерживается в experimental-сборке.
