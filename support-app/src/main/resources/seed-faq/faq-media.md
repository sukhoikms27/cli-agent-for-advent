# MAX — Медиа и файлы

## Какое максимальное качество фото при отправке?
По умолчанию MAX сжимает фото для экономии трафика. Чтобы отправить в оригинальном качестве:
при выборе файла → три точки → «Отправить как файл». Оригинал до 2 ГБ отправляется без сжатия
и без потери EXIF-данных.

## Как отправить фото без сжатия на iOS?
В галерее выбора фото → выделите нужные → три точки внизу → «Отправить как файл» → выбрать
качество «Оригинал». На iOS до 15 версии этот пункт может называться «Файл (оригинал)».

## Почему видео отправляется долго?
Видео кодируется под каждый девайс получателя (H.264 для совместимости). Большие файлы
(от 100 МБ) загружаются дольше. Для скорости отправьте как «Файл» без перекодировки —
получатель скачет оригинал. Скорость также зависит от вашего аплоада: 100 МБ при 10 Мбит/с
аплоада = ~80 секунд.

## Где хранятся полученные файлы?
Android: `/MAX/media/`. iOS: «Файлы → На моём iPhone → MAX». Desktop: «Загрузки/MAX».
Чтобы изменить путь: «Настройки → Данные → Путь загрузки». Файлы из секретных чатов
хранятся в отдельной зашифрованной папке и недоступны через файловый менеджер.

## Как очистить кэш MAX?
«Настройки → Данные → Использование памяти → Очистить кэш». Удаляются превью фото/видео
из кэша; сами файлы остаются в чате. Освобождает от 500 МБ до нескольких ГБ. Не затрагивает
сообщения и контакты.

## Как посмотреть, сколько места занимают чаты?
«Настройки → Данные → Использование памяти». Показан разброс по чатам: медиа, документы,
голосовые. Можно отсортировать по размеру и удалить кэш конкретного чата долгим нажатием.
