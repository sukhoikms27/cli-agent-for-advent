# MAX — Уведомления

## Как отключить уведомления для конкретного чата?
Откройте чат → три точки → «Без звука» (mute). Доступно: 1 час / 8 часов / 2 дня / Навсегда.
Можно настроить: показывать превью текста, звук, вибрацию. Уведомления о звонках мьютятся
отдельно в «Настройки → Уведомления → Звонки».

## Почему приходят уведомления с задержкой?
Проверьте: (1) режим экономии заряда (ограничивает фоновые процессы), (2) разрешение MAX
на работу в фоне, (3) спящие приложения на Android (Xiaomi/Huawei/Samsung добавьте MAX
в исключения), (4) режим «Не беспокоить». На iOS проверьте «Настройки → Уведомления → MAX».

## Как настроить звук уведомления для отдельного контакта?
Откройте чат → три точки → «Уведомления → Звук → Выбрать». Можно выбрать системный или
загрузить свой (MP3/AAC до 1 МБ, до 30 секунд). Кастомный звук не работает в секретных
чатах. Назначенные звуки не синхронизируются между устройствами.

## Что такое «Приоритетные отправители»?
Контакты, уведомления от которых приходят всегда, даже в режиме «Не беспокоить».
Добавляются в «Настройки → Уведомления → Приоритет». Список синхронизируется между всеми
устройствами. Лимит — 50 контактов.

## Как отключить превью текста в уведомлении?
«Настройки → Уведомления → Показывать превью». Опции: Всегда / Только в открытом MAX /
Никогда. В режиме «Никогда» в уведомлении пишется только имя отправителя и «Сообщение».
Не влияет на превью внутри чата.

## Не приходит уведомление о новом сообщении в группе
Проверьте настройки группы: возможно, она без звука (mute). Также группа может быть в
архиве — уведомления из архивных чатов приходят тихо. Если в группе свыше 100 участников,
уведомления по умолчанию только об упоминаниях (mention) и ответах.
