# MAX — Аккаунт и профиль

## Как зарегистрироваться в MAX?
Откройте приложение, нажмите «Создать аккаунт», введите номер телефона и подтвердите его кодом из SMS.
Имя и фото можно сразу или позже — в «Настройки → Профиль». Аккаунт привязывается к номеру телефона,
email указывается опционально для восстановления доступа.

## Как сменить имя и фото профиля?
«Настройки → Профиль → Изменить». Имя до 64 символов, фото — JPG/PNG до 10 МБ.
После изменения новый аватар обновится у всех контактов в течение нескольких минут.

## Как изменить номер телефона без потери данных?
«Настройки → Аккаунт → Сменить номер». Старый номер должен быть активен (на него придёт код),
новый — доступен для приёма SMS. Чаты, группы и медиа переносятся автоматически.
Контакты, у которых сохранён старый номер, увидят уведомление «Этот пользователь сменил номер».

## Что такое MAX ID и где его найти?
MAX ID — ваш уникальный публичный идентификатор (формат `@username`). Находится в
«Настройки → Профиль → MAX ID». По нему вас можно найти в поиске без раскрытия номера телефона.

## Как удалить аккаунт?
«Настройки → Аккаунт → Удалить аккаунт». Действие необратимо: все чаты, медиа и группы удаляются
в течение 24 часов. Перед удалением рекомендуется экспортировать чаты
(«Настройки → Данные → Экспорт»). Удаление аккаунта освобождает MAX ID для регистрации другим
пользователем через 30 дней.
