## Архитектура приватного сервиса

```
CLI-агент (laptop)
    │ HTTPS + Bearer token
    ▼
Caddy (VPS, :443) ── auto-HTTPS (Let's Encrypt) + Bearer auth
    │
    ▼ 127.0.0.1:11434
Ollama (VPS) ── qwen2.5-7b-vps (Q5_K_M, num_ctx 8192, num_parallel=1)
```

- **Бюджет:** Hetzner CX32 (~€6.5/мес, 4 vCPU/8 GB NVMe) — single-user чат, 10-15 tok/s на CPU.
- **Модель:** qwen2.5:7b-instruct Q5_K_M (~5 GB) — sweet spot качества/RAM для 7B.
- **Контекст:** `num_ctx 8192` (KV-cache ~1-2 GB) — главный OOM-предохранитель.
- **Безопасность:** Ollama bind 127.0.0.1 (не торчит наружу), Caddy проверяет Bearer, firewall
  22/80/443, SSH ключи + fail2ban.

## Подключение CLI-агента (дни 25-29)

```bash
CLI_AGENT_PROVIDER=ollama \
CLI_AGENT_BASE_URL=https://llm.ВАШ-ДОМЕН.ru/v1 \
CLI_AGENT_MODEL=qwen2.5-7b-vps \
CLI_AGENT_API_KEY=ВАШ_ТОКЕН \
./gradlew run --args="chat"
```

Или live-switch из REPL: `/local on qwen2.5-7b-vps` (день 26) после `/config set baseUrl/apiKey`.
