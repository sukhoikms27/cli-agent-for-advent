## Итоги Research (консилиум)

Консилиум из Kotlin-разработчика и Архитектора проанализировал кодовую базу:
- **Multi-provider уже реализован в день 25** (`LlmProvider.OLLAMA`, `LlmClientFactory.create()`),
  но `/config set provider ollama` требует restart chat.
- **Главный архитектурный факт**: весь wiring (`ChatCommand.run():110-251`) — локальные `val`,

  `buildSession(config)` pure-fn (28), `ModelLimitsRegistry` (29), `setLlmField` persist (30).

## Проблемы и откаты

- **Qwen3 thinking-модель — пустые ответы** (найдено в Validation): qwen3:14b тратит токены на `<think>`
  блок до ответа. Без явного `max_tokens` Ollama обрывает рано → `content` пустой. Малый `num_predict`
  (10-50) даёт тот же эффект даже через native `/api/chat`.
  - **Решение:** `LocalSmoke.runSmoke` передаёт `maxTokens=2048` (достаточно для thinking + ответ).
    `max_tokens:2000` даёт корректный ответ `'hello'` за 185 completion tokens.
  - `chat_template_kwargs.enable_thinking:false` через `/v1` НЕ работает в Ollama 0.31.1 (не пробрасывается).
  - Добавлен тест `runSmoke sets maxTokens to avoid empty answers from thinking models` (защита регрессии).
- **Ollama error в HTTP 200** (найдено субагентом в тестах): Ollama при CUDA crash возвращает
  `{"error":"..."}` с HTTP 200. `checkHealth()` теперь детектит `parsed.error` после парсинга.

## Архитектурные решения

1. **`AgentSession` holder + `buildSession()`** — весь wiring вынесен из `run()` в чистую фабрику.
   `memoryStore`/`chatId`/`ragEmbedder` — ВНЕ session (переживают switch). Seam для дней 27-30.
2. **`handleLocal` возвращает `AgentSession?`** — null при status/smoke (без switch), новая session
   при on/off. REPL-loop сам закрывает старую через `session.close()` и присваивает новую.
3. **Overlay config без перечитывания env** — `/local on` делает `.copy(provider, baseUrl, model, apiKey="")`
   на текущем объекте AppConfig. НЕ зовёт `ConfigRepository().load()` (env перебил бы overlay).
4. **`savedCloudConfig`** — сохраняется при первом `/local on`, восстанавливается в `/local off`.
5. **Persist выбора** — `setLlmField("provider", ...)` в config.json (runCatching, не роняет switch).
   Seam для дня 30: VPS стартует с правильным провайдером.
6. **ragEmbedder shared** — создаётся один раз в `run()`, передаётся в каждый `buildSession`.
   `AgentSession.close()` его НЕ трогает (иначе switch ломал бы общий HttpClient).
