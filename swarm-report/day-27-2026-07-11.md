## Архитектурные решения

1. **Бейдж в REPL-цикле после `dispatchFreeText`** (не в `onEmit`) — одна точка покрывает оба пути
   рендера: stage-flow (оркестратор эміттит несколько блоков) и обычный чат. В `onEmit` бейдж
   дублировался бы перед каждым блоком стадии.
2. **Pure-fn `providerBadgeText`** — тестируется без мока терминала (в отличие от `printProviderBadge`).
   Инвариант: только `OLLAMA` → local, остальные → cloud.
3. **`/local mark` runtime toggle** (как `savedCloudConfig`) — session-scoped var, без persist в
   config.json (preference сессии). Default OFF — backward-compat.
4. **`/cost` local-free детект по `Price(0,0)`** — без передачи `resolvedProvider` в `printCost`
   (не меняет сигнатуру). Работает для любого бесплатного провайдера.
5. **Суффикс-бейдж (не префикс)** — отдельная строка ВНЕ markdown-блока, как `printDuration`.
   Не ломает markdown-рендер. `--no-color` → plain-текст.
