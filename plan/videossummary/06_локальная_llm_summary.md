**Источник:** 6 неделя 6 поток v1.mov

## Главная идея

Локальные LLM — это те же облачные нейронки, только развёрнутые на твоём устройстве. Бесплатно, приватно, без интернета.

---

## Почему не облако?

| Проблема | Детали |
|---|---|
| **Дорого** | $200/мес подписка, отобьёшь за пару лет на Mac Mini |
| **Нет приватности** | Твои данные уходят на сервер по определению |
| **Зависимость от интернета** | Упал WiFi — нет кодинга |
| **Цена растёт с нагрузкой** | Чем больше пользуешься, тем больше платишь |

Локально: платишь один раз, масштабируешь бесплатно.

---

## Как устроена LLM

```
Запрос → [Input Layer] → [Hidden Layers × N] → [Output Layer] → Ответ
                              ↑ self-attention / transformers
```

**Forward propagation** — предсказание: модель угадывает следующие слова  
**Backward propagation** — обучение: пользователь корректирует → веса перестраиваются

### Ключевые термины
- **Веса** — числовое значение связи между нейронами
- **Нода** — отдельный нейрон
- **Layer** — группа нейронов на одном уровне
- **Параметры** — совокупность весов (выражается в миллиардах: 7B = 7 млрд)

---

## Параметры и память

| Размер | VRAM (fp16) | Железо |
|---|---|---|
| 1B | ~2 GB | Любой ноутбук на CPU |
| 3B | ~6 GB | GPU Intel / слабая видюха |
| 7B | ~14 GB | Нормальная дискретная видюха |
| 13B | ~26 GB | RTX 3090/4090 |
| 70B | ~140 GB | Mac Studio / кластер |

**Формула:** параметры × 2 байта (fp16) = VRAM в гигабайтах

---

## Квантизация — главная магия

Уменьшение точности весов для экономии памяти:

```
float16 (2 байта) → INT8 (1 байт) → экономия в 2 раза
float16 (2 байта) → INT4 (0.5 байта) → экономия в 4 раза
```

**Пример:** 70B модель:
- float16 = 140 GB VRAM (нереально дома)
- Q4 = ~35 GB (один Mac Studio)
- Q8 = ~70 GB (доступно, минимальная потеря качества)

**Обозначения в названиях моделей:** `Q4_K_M`, `Q8_0`, `IQ3_XS` и т.д.  
**Правило:** Q4-Q6 — хороший баланс, ниже Q4 — заметная деградация

---

## Сравнение с облаком

| | Локальная | Облачная |
|---|---|---|
| Скорость | Медленнее | Быстрее |
| Качество | Ниже (7B ≈ GPT-3.5) | Выше |
| Цена | Разово (железо) | Ежемесячно |
| Приватность | Полная | Нет |
| Интернет | Не нужен | Нужен |

Для простых внутренних задач — 7B хватает.

## Инструменты

- **Ollama** — простой запуск через CLI и HTTP API ⭐ (использовали в task26)
- **LM Studio** — GUI интерфейс, удобно для новичков
- **llama.cpp** — максимальный контроль, низкоуровневый
- **MLX** — для Mac на Apple Silicon

**На мобильных устройствах** — 1-3B модели через llama.cpp (без интернета в степи)

---

## Use Cases

1. **Offline ассистент** — работает без интернета
2. **Суммаризация документов** — отдал старый комп с GPU в бухгалтерию
3. **Автодополнение кода** — встраивается в IDE, код не уходит на сервер
4. **Чат-бот** — локальный, данные не утекают
5. **Классификация** — закрытые документы без отправки в облако

---

## RAG + Локальная LLM = мощная связка

```
Документы → Embedding → Векторная БД
                              ↓
Запрос → Поиск → Контекст + LLM → Ответ
```

**Почему это маст-хев:**
- Решает проблему устаревших знаний (опенсорс модели выходят с задержкой 3-12 мес)
- Снижает галлюцинации (ответ привязан к конкретным документам)
- Расширяет знания модели без дообучения
